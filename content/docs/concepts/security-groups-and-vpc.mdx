Part 1 opened port 3000 to your IP. In Part 2, "Connect to an EC2 compute resource" created two security groups so only the instance can reach the database.

## What this page will cover

- VPC, subnets, route tables, and internet gateways, drawn as one picture
- Public versus private subnets, and why the database has no public address

- Why "My IP" beats "Anywhere" for a workshop app
- Security groups versus network ACLs
