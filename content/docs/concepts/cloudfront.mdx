A content delivery network (CDN) keeps copies of your files in many places around the world, so each visitor downloads from somewhere close. Amazon CloudFront is AWS's CDN.

- **Origin**: where the real files live. Often an S3 bucket, or a load balancer for a dynamic app.
- **Edge location**: a CloudFront site near users. It caches what it serves.
- **Distribution**: your CloudFront setup, with its own domain name and HTTPS certificate.
- **Origin access control (OAC)**: lets CloudFront read a private S3 bucket. Turn on "Block all public access" on the bucket and the files are reachable only through CloudFront.

## When to use it

- Any public website or static assets: pages load faster and the origin sees less traffic.
- Serving an S3 site over HTTPS on your own domain.
- See [Static site](/docs/architecture/6-static-site).
