Elastic Load Balancing (ELB) spreads incoming traffic across targets: EC2 instances, containers, IP addresses or Lambda functions. It checks each target's health and only sends traffic to healthy ones.

## Three kinds

| | Application (ALB) | Network (NLB) | Gateway (GWLB) |
|---|---|---|---|
| Works at | Layer 7: HTTP, HTTPS, gRPC | Layer 4: TCP, UDP, TLS | Layer 3: IP packets |
| Use it for | Websites and APIs. Routes by path or host name | Very high throughput, static IPs, non-HTTP traffic | Passing traffic through firewall appliances |

For a web app, use an ALB.

## Words you will see

- **Listener**: the port and protocol the load balancer accepts, such as HTTPS on 443.
- **Target group**: the set of targets it forwards to, with a health check (for example, `GET /` must return 200).
- **Cross-zone**: the load balancer itself runs in every AZ you choose, so it is not a single point of failure.
