DNS is the internet's phone book: it turns names into IP addresses. Amazon Route 53 does three jobs:

1. **Registers domain names**, such as `example.com`.
2. **Answers DNS queries** for the domains you host in it. Each domain is a *hosted zone*, holding *records*.
3. **Checks health**, so it can stop sending people to an endpoint that is down.

## Records you will use

- **A** record: name to IPv4 address. **AAAA**: to IPv6. **CNAME**: name to another name.
- **Alias** record: Route 53's own type, pointing a name at an AWS resource such as a load balancer, CloudFront or an S3 website. Works at the top of a domain, where CNAME cannot.

## Routing policies

Simple (one answer), weighted (split traffic by percentage), latency (nearest Region), failover (a backup when the main one is unhealthy), and geolocation (by where the user is), among others.

## In the lessons

The lessons use the instance's raw public IP address. A real app gets a name: an alias record pointing at a load balancer or CloudFront.
