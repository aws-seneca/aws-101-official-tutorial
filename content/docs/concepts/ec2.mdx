## In the workshop

Part 1 launched a `t3.small` instance running Amazon Linux 2023, then installed and ran the app on it.

## What this page will cover

- What an instance is: AMI, instance type, storage, and networking
- Instance families and sizes, and why the build needed a `t3.small`
- Connecting: EC2 Instance Connect versus SSH key pairs
- Public and private IP addresses, and what happens to them on stop and start
- Instance lifecycle: running, stopped, terminated, and what each costs
