## What this page will cover

- What moved and what did not: the app is stateless now, the database holds the state
- The security groups "Connect to an EC2 compute resource" created, drawn out
- What RDS handles for you: backups, patching, failover options
- What is still fragile: one EC2 instance, a password in a `.env` file
- Next steps: Multi-AZ, and Secrets Manager with an IAM role instead of `.env`
