Package the app as a container image once, then let Amazon ECS run as many copies as you ask for. With AWS Fargate there are no EC2 instances to patch or size: you set CPU and memory per task.

The Lesson 2 app already has a `Dockerfile`, so this design is the same app with a different way of running it.

## When to use it

- You want the same image on your laptop, in CI and in AWS.
- Several small services, each in its own container.
- You want horizontal scaling without managing instances or AMIs.

## Trade-offs

| | |
|---|---|
| Cost | Pay per task for CPU and memory while it runs, plus the load balancer |
| Complexity | You need to learn images, registries and task definitions |
| Scaling | ECS service auto scaling adds or removes tasks |
