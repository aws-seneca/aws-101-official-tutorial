---
title: Tear it down
description: Delete everything you created, so nothing keeps billing.
---

<Callout type="warn" title="Do this today">
Instances and databases cost money for every hour they exist, even when idle.
</Callout>

1. **RDS console**: select `aws-101-signups`, **Actions**, **Delete**. Untick *Create final snapshot* and *Retain automated backups*, tick the acknowledgement, confirm.
2. **EC2 console**: select `aws-101-app`, **Instance state**, **Terminate instance**.
3. Check both lists are empty (the database takes a few minutes to disappear).

Want a safety net? Set up an AWS Budget that emails you before spending anything: see [Costs and the free plan](/docs/concepts/costs-and-free-plan).
